# AI Hunt — AI Tools Directory

> Discover the best AI tools, all in one place.

AI Hunt is a clean, fast, and responsive web directory that helps users explore and find AI tools across multiple categories like Writing, SEO, Marketing, Design, and more.

---

## 🌟 Features

- 🔍 **Search Functionality** — Quickly find AI tools by name or keyword
- 🗂️ **Categorized Listings** — Tools organized by category (Writing, SEO, Marketing, Design, etc.)
- ⚡ **Fast & Responsive UI** — Works seamlessly across all devices
- 🧩 **Dynamic Rendering** — Tools rendered dynamically using JavaScript DOM manipulation
- 📦 **Manual Data Management** — Curated and maintained tool listings
